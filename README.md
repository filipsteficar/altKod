## 🧱 Tech Stack of altKod.com

We like things **fast, simple, and modern**:

* **Astro** → static-first, insanely fast frontend
* **PocketBase** → backend + auth + database (all-in-one)
* **Tailwind CSS** → utility-first styling
* **Alpine.js** → just enough JavaScript

No bloated stacks. No unnecessary complexity.
